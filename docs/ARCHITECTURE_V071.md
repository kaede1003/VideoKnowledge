# V0.7.1 信息流

标签音频 → 浏览器持久缓存 → 本地SQLite有序接收 → 重叠声音窗口 → 原始ASR → 可选本地翻译 / 独立纠错建议 → 原文+候选+疑点 → 用户修订映射 → 模型整理输入 → 单独结果历史。

原始ASR（original）不被译文/纠错覆盖；text是当前显示结果；translation为机器候选；translationStatus=needs_review时text继续是原文。textOverrides由扩展存储，按固定片段ID映射，与ASR事件分开。
自动来源始终machine_unverified；human_edited仅表示人工输入，并不声称程序听音核验。文档带来源数量、待核对数量、模式和生成时间。旧文档不会悄悄重写。

只读取在本轮相邻时间/边界内的识别原文作为翻译参考，不把过去译文/摘要作为原始证据。窗口默认为12秒，右侧重叠2.4秒；停止/边界会刷新短尾段。前次机器文字不作为下一轮ASR提示。
