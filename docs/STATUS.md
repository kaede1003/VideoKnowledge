# 当前状态 · V0.12.1 / git-r18

用户现场发现“文字稿”模式生成的正文仍是西班牙语。根因是文字稿专用分支只做标点/排版，直接消费阅读层文本；当 ASR 译文关闭、失败或被标为待核对时，阅读层按保护规则回退到原文，而文字稿分支没有自己的翻译步骤。git-r18 在短文和长文两条文字稿路径中增加独立的简体中文翻译阶段，逐条保留说话人/来源ID，先翻译再断句；可信的 ASR 中文译文可复用，待核对/失败/关闭的译文会重新翻译。原始识别和旧文稿均不覆盖。

翻译结果必须通过结构、ID、中文内容及阿拉伯数字校验；若模型仍返回外语或结果不完整，本次生成明确失败并保留原文/旧文稿，不再把西班牙语冒充中文交付。短文/长文端到端模拟与完整单元测试通过。**尚未用用户真实视频及实际 Ollama/Qwen 文字模型进行双语质量验收**，译文专名、否定、数字和语义忠实度仍需人工抽查。

详见 [git-r18升级说明](UPGRADE_GIT_R18_TRANSCRIPT_TRANSLATION.md) 和 [测试报告](../qa/GIT_R18_TRANSCRIPT_TRANSLATION_TEST_REPORT.md)。

# 当前状态 · 本地服务 V0.12.1 / git-r16
