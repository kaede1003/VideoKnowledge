# V0.9.0：页面开始听写与连贯成稿

组件组合：**Edge扩展0.9.0，本地服务0.8.0，安装器0.8.1，VKN5协议5**。本次只修改扩展业务代码，不安装新模型、不变更后端协议和数据目录。

## 原地升级（0.8.0已有用户）

1. 停止听写/采图，等已缓存内容处理结束；导出重要笔记。关闭旧设置页。
2. 将升级包内的`extension`文件夹合并覆盖原加载路径，例如`D:\VideoKnowledge_Git_Project\extension`。不要套成`extension\extension`，不要卸载原扩展或新建另一个副本。服务可继续使用原0.8.0；此次无需重跑INSTALL_ALL。
3. 打开`edge://extensions/`，重新加载原扩展；如果因新增`desktopCapture`权限暂停，检查权限提示后重新启用。此权限仅用于主动点击后打开“标签页＋音频”选择器，代码没有提供屏幕、窗口或麦克风采集选项。
4. 刷新视频页面，确认面板版本0.9.0，再重新打开设置。保持原路径和扩展ID，已有笔记、模型和Ollama来源许可不需要清空。
5. 历史文档不会被自动重写；选择模式重新生成，才能使用新格式。选择“导出整理结果”得到正文；“导出全部笔记 / 原文”是备份，仍保留历史阶段与原始疑点。

## 新视频怎样开始

### 方式一：在视频页面点“开始听写”

已有当前标签授权时直接使用它。尚无授权时，扩展弹出浏览器自己的共享选择器：**请选择正在记笔记的这个视频标签，并勾选“共享标签页音频”**，再确认。无需先到工具栏点击插件。

没有勾选音频、取消、在授权期间停止、或目标页面的视频已变更时，不会宣布听写成功。停止也会关闭待确认选择器，迟到结果不会重新开启录音。

**不是一次授权所有标签或永久静默录音。** 浏览器选择器仍需用户确认，站点政策也可能禁用共享。选择器不会提供可靠的已选源标签ID供本扩展核对；选错标签可能导致音频与当前笔记/时间轴不符，务必选择当前视频。未知浏览器/策略不支持时用方式二。

### 方式二：Alt+Shift+V

在视频所在标签按该原生扩展快捷键，相当于合法调用扩展的开始/停止动作，不用鼠标点工具栏。快捷键冲突或未绑定时在`edge://extensions/shortcuts`为“视频知识笔记”绑定“激活扩展”。操作系统/浏览器可能保留部分键位；可自行换键。

原工具栏图标保留。网站访问权限若设置成“点击时”，页面按钮可能要先允许在YouTube/B站运行扩展；站点访问权限与标签音频授权是两回事。普通刷新、新标签或切换视频不承诺自动继续录音；这版不实现跨页面静默录音。

## 结果现在怎样呈现

- 实时记录默认折叠，展开后把连续同人的多个采样片段展示成一次发言，不再每6/12秒强制成一行。已有标点分句，每句另起一行；没有标点时等待手动文字稿断句，不给实时音频增加逐句文字模型调用。
- 同一session/同一声音ID、可信分组状态、相近时间才合并；换人、长停顿、拖动跳转、明显重叠、归属不清、被排除资料造成的间隔都不跨越。A-B-A维持问答顺序，不把全片同一人的话集中在一起。
- “文字稿”先合并发言，再让模型只补标点。逐条检查字符、数字及英语词边界；改字、漏句、错ID、无效JSON或断句超时就保留对应原字，详情记录本次退让。既有上下文纠词步骤独立运行，并保留修改对照。
- 知识整理内部按容量取材，再统稿为连贯文章；剧本按场景/事件和“角色：台词”；小说按情节衔接为正文；自定义严格按补充要求。真实标题如“第一章 雨夜”可以保留，处理标签“整理分段1/6”不进入新正文。
- 资料疑点、时间戳、修订理由都在“来源与校对详情”和原始记录内，不在每句话后打断阅读。模型若明确返回AI评论或编辑附录，也迁入详情。原说话人确实说的“我不知道/需要确认/可能”必须保留，不能当作AI评论删除。
- 复制、TXT、Markdown、HTML、完整阅读使用同一份成稿。审计JSON另含来源、修订和结果详情；正文导出不是备份。

## 未完成与限制

原生Windows Edge、真实tabCapture/desktopCapture选择器、真实Whisper/Ollama的速度和质量未在本次环境验收。新页面入口有构造测试，不代表所有Edge策略均可用。新的`desktopCapture`不能绕过授权或DRM。

**100秒总请求期限、非流式、MV3后台生命周期及持久续跑仍是独立未完成项。** 知识多块会增加最终统稿调用，可能更耗时；不要因最终标题变连贯而认为性能问题已修复。取材超出本版统稿上限会显式失败，不截掉正文假报完整。文字稿某块回退不删除原字，但可能没有补足标点。

合并和标点校验不能恢复原来听错的词；文字错误仍需原音证据。标点也可能影响含义，保留字词不等于语义100%正确。无可靠声音标签的旧笔记不会被强行推断为同一发言者。书写/小说质量仍取决于实际模型，提示词不保证永不输出旁注。

## 实机验收

新视频页不点工具栏→页面开始→选择当前标签+音频→开始后只播放这页→停止→取消另一轮选择器→确认无新时间段录音。快捷键单独测试。随后用两人轮流对话样本，检查合并没有跨人、文字稿没有漏句/AI旁注，正文导出和原文审计均可用。关闭后重开页面，应仍能读取旧笔记与文稿历史。
