# V0.10.0 · 字幕辅助校正、短片段衔接与布局修复

版本：Edge扩展 **0.10.0** ／ 本地服务 **0.10.0** ／ 安装器 **0.8.1** ／ 协议5 ／ git-r5。
基于已交付V0.9.0源码修改，保留原始听写、人工修订、译文、文稿历史和已有模型。本版不是从头重做。

## 原地升级

1. 暂停视频，停止采集，尽量等缓存补录结束，导出重要笔记。关闭设置页；在原目录运行 STOP_LOCAL_ASR.bat。
2. 把升级包内容合并覆盖到原工程，例如 D:\VideoKnowledge_Git_Project。应得到 extension/manifest.json、server/caption_review.py，不能套成 extension/extension。
3. 保留 .venv、ASR_SETTINGS.bat、模型和音频数据库。不要卸载扩展、创建另一个副本或更改原加载目录。
4. 运行 START_LOCAL_ASR.bat 或 START_ACCURATE_ASR.bat，只开一个；检查 /health 或 CHECK_LOCAL_SERVICE.bat，服务应为0.10.0。
5. Edge打开 edge://extensions/，重新加载原扩展至0.10.0；刷新视频页。模型/一键安装器无需因为版本变化重装。
6. 开始一轮听写。面板的“对照视频字幕纠错”默认开启，细项在折叠的“字幕校对”里。旧文稿是历史快照，重新生成才使用新的修订。

本次必须同时覆盖后端和扩展。仅更新扩展会因旧服务没有校验路由而暂缓字幕校对，不应影响原有语音记录。

## 字幕如何用于记录纠错

语音仍是主记录。先正常显示ASR，再把同一录音会话、同一跳播边界、重叠时间里的字幕作为证据；核对结果更新同一条记录的显示文本，不把字幕另外抄成重复行。

1. **优先直接读取**：已加载且有活动cue的HTML字幕轨道，或YouTube/B站当前显示的专用字幕元素。不会重新加入“获取整段字幕/继续字幕记录”按钮，不下载隐藏字幕文件，不把弹幕/网页正文当字幕。
2. **画面采样后备**：没有可读字幕时，使用已经授权的标签视频流，只裁剪播放器底部区域，取相隔约450ms的两帧，送至本机 `qwen2.5vl:3b`。不给视觉模型ASR文字，降低照抄听写的倾向；无清晰字幕就返回空。
3. **保守局部采用**：时间和会话吻合、字幕多次稳定出现、与原句相似度足够且局部汉字同音，才自动采用。只做小范围、等字数的词语修订，不把某一条短字幕替换成整段12秒的听写。
4. **冲突保留**：明显差异、自动生成字幕、外语原声配中文字幕、数字/否定/姓名风险、时间不吻合时，不强制覆盖；候选与原因放在折叠的来源详情。
5. 原始听写不变；人工修改优先；每条已采用字幕修订可以撤销。以后ASR修订了原文，不再沿用绑定旧原文的修订。

本轮自动局部替换主要支持中文同音词。英文等其他原语言、异语译字幕只能留作证据，**没有实现任意语言字幕融合，也没有实现以译字幕替换翻译正文**。

画面采样只在播放且听写开启时进行；暂停、停止、跳播、换视频会停止或换代。播放器应完整可见，字幕位置需落在底部裁剪范围。裁剪不到、黑屏/DRM或模型不可用时明确暂缓，不绕过限制；暂停的新音频停止后，已有缓存可继续补录。

两帧一致不等于字幕正确，网页自动字幕也可能来自同样的语音识别。当前标记无法识别所有“自动生成/翻译字幕”来源。匹配阈值未经真实节目准确率校准，不能宣传百分百纠错。

## 本地组件与性能

已有 `qwen2.5vl:3b` 和pypinyin即可复用；缺少时运行原一键 `INSTALL_ALL.bat`，只补缺项。没有视觉模型时，能读到文本字幕的路径仍可运行；没有拼音组件则保留候选、不自动替换。

帧分析最多一个在途请求；本页手动整理、阶段摘要或LoRA采图忙时退让。视觉推理超时/失败后有退避，独立于音频队列。它仍会与本机Ollama其他任务竞争，不能保证没有GPU负载；不需要画面分析时可以关闭折叠区里的画面采样选项。

仅向127.0.0.1发送裁剪图片；不会新增云端图片上传。图片仅在请求内存中使用，不写入视频缓存或LoRA数据集；保存的是字幕文字、时间范围、来源与帧哈希。该缓存每份笔记最多6000条；超过后仅保留近期证据，原始听写和已保存修订仍在。不是每帧分析，也不能保证短暂字幕全部采到。

## 无关内容过滤已移除

移除主开关、关注主题、分类状态、人工纳入/排除按钮及定时主题模型调用。旧配置与排除标签不再决定整理输入，所有选定时间范围内的原始记录均进入流程；低识别质量只保留提示，不作为自动删除条件。

旧筛选元数据为审计兼容而保留，但不生效；无需清空笔记。知识摘要仍按该文体做概括，这与先行自动过滤记录不是一回事。用户自己在整理要求中指定的范围继续有效。

## 单字、残句和上下文纠错

- 连续同一说话人且时间相邻的短尾字或前缀可接回发言；只在明确同ID或两侧一致的严格条件下继承短片段的展示分组。
- 未知说话人的极短无标点相邻片段可展示在同一未归属段内，但不猜角色。单独的“是/不”等可能独立回答的短句不因字数短就吞并。
- 换人、抢话、长停顿、不同录音、跳播边界不跨越；原始碎片及声音标签保留在来源详情。
- 整理前同音纠词现在附前后各两条同会话上下文与字幕依据，也能检查两字短语；只有普通低声学分数不再一律拒绝检查。明显循环、缺失、数字/否定/专名等仍不凭推理补造。
- 推断候选经连续原文引用、拼音和局部修改守卫后，才影响本次整理；简要修订依据在详情，不插进每句话后面。

## 生成后的空白区

移除面板固定占位高度；无结果时不渲染结果区域。生成中保留已有成稿，失败/取消不插入空结果。面板高度跟随内容且有视口上限，正文、来源和导出菜单均有明确布局。跳转结果只滚动面板内部，不再用可能推动宿主网页的 scrollIntoView。

这修复了源码中可确认的布局风险，并在合成页面测试了三个窗口宽度。尚未在用户报告的那一页原生Edge现场复现，不能排除站点CSS/缩放/浏览器策略等其他因素。

## 验收与限制

推荐用字幕清楚、无弹幕干扰的短片段检查：开始→两种字幕来源→听写修订与原文对照→撤销→暂停/跳播/停止→生成→取消/失败→正文导出。自动校正不恢复未采集声音，也不自动纠正旧笔记未采样的历史画面。

本版没有修复长文整理的固定100秒非流式等待、持久任务和续跑。这是独立待办；不要通过重装模型当作解决方案。

实际测试证据见 qa/V0100_TEST_REPORT.md。没有真实Whisper/Ollama/Edge端到端准确率测试。
