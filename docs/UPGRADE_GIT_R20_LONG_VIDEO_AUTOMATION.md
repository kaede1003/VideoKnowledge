# git-r20 升级说明：长视频稳定性与自动决策

## 适用范围

以用户已有 git-r19 为基线，原位更新扩展及其后台 JavaScript。保留 git-r18 外语文字稿翻译、git-r17 Sherpa-ONNX 1.13.8 版本检查、git-r16 原生说话人进程隔离。本轮**不更换 ASR/Ollama/Sherpa 模型**，不修改 API Key、本机权限、驱动和 Windows 系统设置。

## 变化与原因

1. **超过一小时的插件界面卡顿**：原实况转写每包重新扫描全部历史、重建大量 DOM、序列化/保存整份会话。现在用 O(批次) 的 ID 合并快路（乱序/旧数据回退完整合并）；可见文字稿只显示最后30轮并有“加载更多”，按需向前扫描，不影响缓存/导出完整记录；130ms 合并重绘，运行中约3.2s 去抖写入，最多12s强制刷新，关闭/切换视频前即时保存。
2. **约两小时的知识/文字稿生成失败**：浏览器 Manifest V3 后台任务不适合持有超长单次消息。超过既有约4300估算 tokens 门槛的整理，将输入保存到本地临时键，只做一次模型调用就保存阶段检查点并返回“继续”，由网页自动发送下一条短消息。每次本地模型流式调用有90s空闲、195s总上限。期间不能把后台 worker 退出冒充成功，手动再次点击可从相同来源指纹的检查点续跑。
3. **检查点长期膨胀、主题统稿不收敛**：r19 单个 JSON 反复整份写入、最终整理试图不断递归缩减。r20 将各阶段输出写入独立 Chrome storage 键并缓存读取，可迁移之前同输入指纹的 r19 检查点；最终统稿采用限定的分组及主题节输出，必要时保留已生成分节并说明跨节可能仍有少量重复，不丢弃来源/已完成内容。
4. **说话人角色自动判断**：结合已有声学编号、同一声纹多轮发言与邻接对话，由本地模型直接给“主持人/受访者/旁白/讲述者”等证据支持的身份称呼，随新增证据可以自动更新，不要求逐条人工批准。声纹无法识别或真实姓名无明确台词/字幕依据时继续标记未知，不臆造真名。
5. **减少“疑点/审核”**：普通词级时间戳缺失、仅供参考的纠正建议不再一律增加待审计数；能按原文校验的低风险提示模型自动处理。原始转写与建议保留在记录中。疑似数字、否定、外语翻译扭曲等真正高风险情形仍会提示，不能仅凭模型自信度静默篡改事实。

## Windows 原位升级

1. 暂停听写、停止服务，复制原项目和扩展的备份。记录当前扩展**加载目录**，勿删除原扩展、勿“清除扩展数据”。
2. 将 r20 ZIP 解压，按相同目录结构覆盖原 `VideoKnowledge_Git_Project` 的源码文件；不要删除 `.venv`、`.venv-qwen`、`models/`、`ASR_SETTINGS.bat`、SQLite、用户笔记、音频缓存与私有设置。
3. 执行 `START_LOCAL_ASR.bat`。本次没有增加 Python / Sherpa / Ollama 依赖，不要重装模型。
4. Edge 打开 `edge://extensions/`，在**原来已加载的那一项**点击“重新加载”；刷新视频网页。
5. 用一段短视频确认可显示实时摘录和知识整理，再使用同一视频的两小时录音或历史记录进入“知识文档”模式生成；生成中可见阶段进度，浏览器后台会连续处理多个批次直到完成。不要在生成期间关闭目标标签页。
6. 如果中途遇到超时、浏览器重启、模型断开，先恢复本地模型连接，然后在同视频同模型同范围再次点击“生成”，应从已持久化块继续。

## 回滚与数据兼容

- 回滚：停止录制/整理、备份现有工程，将源码恢复 r19 并重载**同一扩展**。r20 新产生的分片检查点在 r19 不可直接继续，但原始录音、字幕、原转写、已保存的知识文档和旧 r19 检查点不被主动删除；r19 对同一输入可能重新执行整理。
- r19 单体检查点在第一次 r20 续跑时会迁移到分片，迁移完成后删除单体内容字段、保留元数据；因此强烈建议升级前先备份。
- 自动续跑过程中临时来源输入可能保留在扩展本地存储中，默认24小时有效，不发送到远端；临时数据并非原始音频缓存。不要因清理临时键而清空存储。
- 本版的人工选择“取消”不会停止其他应用的 Ollama 模型任务，也不会清除已有证据；网络/磁盘错误会停止本次生成并保存最近的稳定阶段。

## 验收边界

已执行合成2小时转写、阶段暂停续跑、分片检查点/旧版迁移与浏览器 DOM 测试；这些验证不能证明你的 RTX5080、本地模型、Edge 在真实两小时负载下完全不卡、角色百分之百准确或主题全部无重。若同一视频继续失败，请保留错误消息、模型名称、时间点和 `diagnostics` 日志（注意脱敏），以便针对实际失败阶段继续定位。
