# 视频知识笔记 V0.7.2 · 可逆内容筛选

本补丁基于 V0.7.1。**扩展升级为 0.7.2，本地听写服务仍为 0.7.1，属于正常组合。** 不需要重装 Python / Whisper / Ollama，不需要下载新模型。

## 安装

1. 导出重要笔记；停止采集，尽量等缓存补录结束。关闭旧设置页。
2. 将升级 ZIP 中的 `extension` 文件夹合并覆盖到原来的项目目录，例如 `E:\VideoKnowledge_Edge_v0.3\extension`。不要套成 `extension\extension`，不要卸载原扩展；保留原加载目录及 ID。
3. 在 `edge://extensions/` 对原扩展点“重新加载”，确认 0.7.2；刷新视频页。当前版本的本地服务无需重启，模型与缓存不变。

升级包不含 `.venv`、`ASR_SETTINGS.bat`、用户数据库或模型权重。本次没有修改后端依赖、音频协议或浏览器权限。完整包包含 0.7.1 后端；已有用户优先用升级包，避免覆盖自己的启动配置。

## 使用

主面板新增一项 **过滤无关及可疑内容（原始记录保留）**，默认开启。复杂操作收在 **内容筛选** 折叠栏。

- **默认轻量模式**：不新增任何模型请求。每批转写到达后，根据已有质量指标、长串重复、邻近完全同源的短重复片段、纯填充词及明确购买/报名/订阅引导给出分类。阶段摘要、本地关键句和手动知识整理统一使用筛选结果，减少把错误反复生成的文字选作“高频关键词”。
- **关注主题**：可留空，也可填写“只整理讨论观点，排除报名宣传”。没有勾选下述本地AI时，这个主题只提供给正式整理提示词及保守规则，不会声称已对所有句子完成语义判定。
- **可选本地 AI 主题判断**：在“内容筛选”勾选；仅使用已经保存的本机 Ollama 文字模型，且只在录制/播放活动中约每分钟处理最多10条、正文约4200字符的一小批。每次最多1200输出token、25秒等待上限；失败保留原文并退让约3分钟。自动判断不会使用云端/自定义接口。开启会增加本机推理负载，最近仍在排查超时时建议先保持关闭。
- **恢复误筛选**：展开“内容筛选”，对某条点“纳入整理”；可点“恢复自动判断”撤销。展开“实时记录”也可对任意条点“不纳入整理”。选择会保存，新生成的文档生效。关闭整个过滤开关会停止应用自动/手动排除，不删除这些选择。

## 筛选规则与边界

识别可靠性、主题相关性、事实真伪是不同问题：

- 识别分数低或异常循环：知识摘要暂缓使用，仍保留文字与时间戳。不能将低分直接视为错误率，也不能断定原音说了什么。
- 高置信的自动“跑题”分类：必须对应本条当前版本、当前主题，并给出能在原文中找到的连续引用，才可能排除。引用匹配只是格式/溯源检查，不证明判断正确；模型仍可能误判。
- 只有译文存疑、原文可用：总结使用原文与疑点标记，不把可疑译文写成确定结论。
- 不能因为是反对意见、反例、陌生内容或关键词不同就自动剔除。保守规则对这类上下文优先保留。
- 剧本、小说、文字稿、自定义模式默认保留对白、铺垫和场景相关文字，不使用知识摘要的自动删减；仍保留疑点标记。人工明确排除仍有效。
- 原始记录不删除，人工修订独立保存；后续转写更新、主题改变会使旧自动分类失效。可选AI关闭后不再应用缓存的主题分类。
- 旧阶段摘要和已生成结果是历史快照，**不会因筛选变化自动重写**。重新生成知识文档即可使用新筛选。要看完整资料仍导出全部笔记或核查JSON。

所有自动判定都可能误报或漏报。本功能是减少错误材料进入总结，不是修复音频、重听原音或事实核验。

## 关于上一条100秒超时

本补丁**没有完整重构长文生成的100秒期限、非流式传输和断点续跑**，不能保证该故障消失。只把错误提示改为更准确的“模型请求等待超时（尚未区分排队/加载/生成）”，并为可选分类设置独立的短时限与退让策略。过滤可能减少输入，但不能代替长任务架构修复。ASR翻译、采图在独立后端运行，本补丁不能保证整个本机Ollama完全没有并发任务。

## 本机验收

先不启用可选语义判断：录制或加载一些内容 → 展开内容筛选 → 确认异常串不进入新摘要且完整原文仍存在 → 手动纳入一条再生成 → 关闭过滤再生成对照。

可选判断需要本机 Ollama 已正常通过推理验证。勾选后继续播放/录制，观察一小批的分类状态；若超时/失败，保持默认轻量模式，不要重复点击。
