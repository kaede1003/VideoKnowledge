## 升级（现有0.6.0，保持原目录和扩展ID）

1. 导出重要笔记。停止采集，尽量等待已接收缓存处理完成，再运行 `STOP_LOCAL_ASR.bat`。不要删除旧笔记、`.venv` 或缓存数据库。
2. 解压升级包，把 `extension`、`server`、`scripts` 等文件夹和根目录文件合并覆盖到原目录（例如 `E:\VideoKnowledge_Edge_v0.3`）。不要再套一层 `extension\extension`。升级包不含 `ASR_SETTINGS.bat`，不会主动修改你的模型选择。
3. 启动 `START_ACCURATE_ASR.bat`（本轮强制small，设备与量化沿用你的设置，默认CPU INT8）；也可运行 `START_LOCAL_ASR.bat` 保留既有模型选择。**二者只开一个。** 本次没有增加必装Python依赖，不需要重装已经存在的模型。
4. 在 `edge://extensions/` 重新加载原扩展，确认0.7.1，刷新视频页并重新打开设置页。不要卸载重装。旧服务必须重启，插件与 `/health` 返回的服务版本均应为0.7.1。
5. 在设置的“本地听写与中文记录”选择视频实际语言（单一中文/英语时，建议指定而不是自动），识别窗口默认12秒，可选6/18秒；保存后重新开始一轮听写。12秒只是音频采样窗口，另有重叠与推理延迟。
6. 用同一段短视频检查“原话 → 识别原文 → 中文译文 → 整理结果”。先检查原文，原文错了不能指望总结/小说润色替你纠正。

## 日常界面

主界面只保留开始/暂停/停止、整理方式、生成和结果。实时记录默认折叠；收到新文字不自动展开。展开后显示最近30条，可加载更早记录；折叠不停止采集也不丢弃记录。

整理方式包括知识文档、剧本、小说、文字稿、自定义要求。补充要求和时间范围藏在折叠区。默认忠实整理；小说/自定义可主动选择创作性润色，输出明确标为改写。画面没有被自动理解，不应据声音编造真实场景。多份结果独立保留，可切换阅读、复制和导出Markdown/HTML/TXT，不覆盖原始记录。

对长篇材料按块逐段处理、顺序合并；不是整部小说的统一文学编辑。超过单次输入上限会明示拒绝，不悄悄截断尾段。跨段人物、剧情一致性仍需核对。生成失败/取消保留旧结果；现有MV3长任务生命周期风险仍需实际Edge验证。

## 保真与核查改动

- 不再把上一段机器听写喂入下一段识别的提示。关闭跨窗口文字条件，仍保留相邻音频重叠和用户主动填写的术语；这可能减少错误延续，也可能降低跨段文字一致性，并非保证不出错。
- 默认窗口从约6秒调整为12秒，降低短音频上下文不足的风险；6/18秒可选。不存在“12秒一定更准”的实测结论，模型计算慢仍会排队。
- 识别结果保留模型名及字词分数、解码分数、疑似非语音/重复提示。分数和阈值只是工程诊断，不是准确率或已校准概率。
- 翻译仅依据原始听写，**不再与纠错共用同一次返回结果**。可选文本纠错只作建议，不自动覆盖原文，也不作为翻译来源。
- 对数字、部分英文否定、推测表达、比较方向、百分比单位和短片段增加检查。可疑译文保留为候选，主要记录继续显示原文，并标为待核对。未知语言不凭空翻译。
- 检查是有限启发式，可能误报/漏报。英文双重否定的正确意译可能被标记；其他语种仅有基础检查。未报警不等于正确。
- 阶段摘要与手动整理保留来源和疑点，可疑译文不作为权威正文送入模型，改用原始识别并明确标记待核对。独立质量提示随生成结果保存；语言模型仍可能不完全遵守提示。
- 修复字幕清理器将 `x < 5 and y > 3` 当作HTML整段删除的缺陷，保留比较表达，只清理明确的字幕/危险标记。
- 实时记录内新增“核对 / 修订”，点击时间戳可回到来源位置。人工输入和原始识别/译文分开保存，后续识别更新不覆盖人工修订，可以撤销。人工修订是用户输入，软件并未验证它确实来自原音。

## 核查导出

“更多工具 → 导出核查 JSON”包含视频来源、时间戳、识别原文、译文候选、质量提示、模型名（有记录时）、人工修订、说话人标签、已生成文档。不含模型接口密钥、登录凭据配置或声纹向量；**包含你自己的视频内容/链接，请检查隐私后再分享。文件不包含音频。**

“导出全部笔记 / 原文”仍可导出可读的Markdown。普通“导出”只保存当前选中的整理结果。

## 旧笔记如何处理

升级不会证明或自动改对既有内容。对旧条目仍应看原话核对，手动修订后重新生成文档；旧结果保留，避免修复时丢失证据。
已处理音频的PCM仍按既有策略清理，仅有文字不能重新做声学识别。需要重新听写时应播放原视频的对应片段，或提供有权限使用的源音频/视频；本版没有增加自动下载视频或绕过保护功能。
本版听写窗口/译文策略只用于升级后的处理，不承诺回溯修复已完成的旧识别。
