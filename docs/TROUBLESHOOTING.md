# 排障顺序

先核对版本和实际加载目录，避免多个同名扩展或旧服务占端口。保留原文/导出；不要用清空数据作为默认修复。

| 现象 | 排查 | 不要做 |
|---|---|---|
| 批处理乱码/不是命令 | 检查文件ASCII/CRLF；使用原包BAT；路径带空格需引号 | 不需要管理员权限，不修改全局编码 |
| 无法连接8765 | 运行START_LOCAL_ASR；CHECK_LOCAL_ASR验证HTTP和WebSocket | HTTP正常不代表WebSocket依赖完整 |
| No supported WebSocket library | 运行依赖明确包含websockets；在同一.venv修复依赖 | 不在另一Python里安装后宣称服务已修 |
| 端口占用 | 检查是否另一个副本运行；用本项目停止脚本 | 不强杀所有Python进程 |
| 本地Ollama403 | 检查实际11434服务；设置页生成精确Origin命令；完整退出再启动Ollama | 不填假API Key，不开放通配来源/局域网 |
| 模型未安装 | 验证模型名；文字/视觉模型不同；按明确选择安装 | 不擅自换云端或大模型 |
| 设置显示有值但运行没有 | 保存→后台读回→实际短推理；确认不是旧扩展 | 短推理通过不是长文成功保证 |
| 超过100秒 | CHECK_AI_TIMEOUT做分项诊断；看ISSUE-001 | 反复点击会重跑，不是可靠续跑 |
| 停止后还在出字 | 比较时间戳，是缓存补录还是新输入；停止全部采集后验证轨道 | 不把关闭面板当停止，不删未处理缓存 |
| 大量重复/同音错词 | 原话→转写→译文→摘要逐层比较；保存疑点/模型版本/时间范围 | 润色、过滤不能证明听写正确 |
| 摘要跑题 | 轻量可逆筛选先开；查看理由与恢复；可选主题AI会增加负载 | 低置信不等于跑题，反例不应删除 |

超时诊断报告在`diagnostics/`，会记录模型与时间但不保存推理正文。该目录默认不提交；需要反馈时先检查个人路径等信息。日志分享不包含API Key、会话token或整份私人笔记。
