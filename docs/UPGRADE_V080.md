# V0.8.0 原地升级：自动说话人、视频缓存、上下文纠词与断线恢复

组件：扩展 **0.8.0**，本地服务 **0.8.0**，VKN5音频协议保持5。基于已交付git-r1/0.7.2工程继续修改，不是重写或空工程。

## 先处理本地服务断开

“连接异常断开”本身不能证明Python进程崩溃，缺少现场堆栈和退出码时不能断言是显卡、模型、内存或杀毒软件导致。先暂停视频，不要清空笔记或音频缓存，不要强制结束全部Python/Ollama进程。

本次修正了可由代码和故障注入确认的路径：

1. 旧WebSocket还未释放时新连接收到永久fatal：改为SESSION_BUSY可重试，不丢弃缓存；旧连接超时后释放。旧连接迟到的回调不再覆盖新连接状态。
2. 本地缓存拒绝一包后，在途的下一包会被误判“序号不连续”：改为关闭本次传输，不确认失败包，按最后已落盘序号重放。
3. 结果推送协程出错却无人收集、工作任务在查询阶段异常后退出：增加监督、状态报告和有间隔的任务恢复；不是无限循环重启整个进程。
4. 增加hello握手期限、应用层心跳、有限退避和断开后HTTP健康探测；区分“服务仍响应”和“暂时无法联系”。后者也可能是繁忙或阻止访问，不直接叫崩溃。
5. 启动器记录本项目子进程的退出码、十六进制Windows状态、Python故障堆栈和日志。不会改驱动、杀其他软件或悄悄重装模型。

诊断位置：工程根目录 `diagnostics/`（不提交Git）。`CHECK_LOCAL_SERVICE.bat`输出`connection-时间.json`。启动日志为`local-service-时间.log`，单个文件约5MiB上限并保留一份轮换；`local-service-state.json`是最后保存的进程状态，若启动器本身被强杀，“running”可能已过时，应与即时health检查对照。

请优先分享诊断JSON；日志可能含本机文件路径，分享前检查。软件不主动记录完整转写、API密钥或音频到诊断JSON。启用故障处理不能保证捕获断电、系统强杀或全部原生库崩溃。

## 升级步骤

1. 导出重要笔记。暂停视频、停止全部采集，尽量等可处理的缓存补齐。服务已经断开时保留浏览器和数据库，别清空缓存。
2. 在原工程运行 `STOP_LOCAL_ASR.bat`；它只匹配原目录虚拟环境的本项目服务。若报告其他程序占端口，不强杀该程序。
3. 将升级ZIP内容合并覆盖原目录，例如 `E:\VideoKnowledge_Edge_v0.3`。不要套成`extension\extension`。不卸载扩展、不改变加载目录；包不含`.venv`、模型、笔记或`ASR_SETTINGS.bat`。
4. 启动 `START_LOCAL_ASR.bat` 或 `START_ACCURATE_ASR.bat`，两者只开一个。新增启动器保留窗口、日志和退出码。不会自动恢复整个崩溃进程。
5. Edge在`edge://extensions/`重新加载原扩展，确认0.8.0；刷新视频页，重新打开设置。访问`http://127.0.0.1:8765/health`或运行`CHECK_LOCAL_SERVICE.bat`确认服务0.8.0。扩展和后端都要升级。
6. 新功能按需要安装下列可选组件。安装后重启服务，不影响已有模型与笔记。

| 入口 | 用途 | 首次联网/许可 |
|---|---|---|
| `INSTALL_SPEAKER_MODEL.bat` | 声学分组模型及组件 | 显式运行才安装；原来已安装则不用重复安装 |
| `INSTALL_VIDEO_CACHE.bat` | yt-dlp下载组件 | 视频需要合并时另需本机ffmpeg；部分YouTube解析需要受支持的Node.js/Deno |
| `INSTALL_CONTEXT_REVIEW.bat` | pypinyin同音校验 | 仅小型Python组件；沿用已有本地文字模型，不下载新LLM |

## 自动说话人：不再填写“男生/女声”

默认新录音使用自动声音分组，不要求用户填写角色名。已保存的手工名称仍保留，但界面不再以命名表单作为使用前置条件。设置中可关闭分组以降低负载。

稳定的分组显示“说话人1、2…”。只有明确的第一人称主持人/嘉宾自述且该段没有识别疑点时，自动附加角色说明，并保存相应原句依据。**这不是声纹查实名、性别推断、画面人物识别，亦不保证识别所有虚构剧情角色。** 没有证据保留编号；抢话和短回应可能待确认。模型缺失时保留转写、明确提示未启用，不伪造交替编号。

原有文字不能凭空补上可靠声学分组；声音特征仍仅在本轮本机音频会话范围内使用。

## 视频保留3天

面板“保存视频（3天）”需用户主动点击并确认有权保存。本版是**完整点播视频下载**，不是仅录制已经观看的部分。当前接受YouTube/B站单个公开视频页面；不接受任意文件URL、直播、播放列表，不读取浏览器cookie、不绕过登录、付费或DRM限制。来源限制/网络失败需明确显示，不以下载一部分冒充成功。

默认最高720p，单视频4GiB上限，总缓存20GiB上限，磁盘剩余低于1GiB停止新增下载；不提前删掉未到期视频来腾空间。并发最多一项。媒体格式根据源和本机ffmpeg可用性为MP4/WebM/MKV；不承诺任何站点和视频都可成功下载。

默认目录：`%LOCALAPPDATA%\VideoKnowledge\video-cache`，可通过启动前的`VKN_VIDEO_CACHE_DIR`调整。每个缓存任务独立UUID目录、所有权标记和SQLite元数据。**下载完成时起算72小时**，重复查看不续期。到期后不再提供新播放访问；服务运行时每15分钟清理一次、启动时也清理。关机/服务关闭时无法物理删除，下一次启动再处理；文件被播放器占用或安全检查不通过会提示并稍后重试。不会删笔记、模型、LoRA样本或目录外文件。

面板“本地缓存”可查看进度、播放完成文件、取消下载、删除本缓存。手动复制到缓存目录外的文件不由插件清理。播放可能在新标签打开，来源令牌短期有效；已经打开的文件句柄可能延迟清理。

## 整理前上下文同音纠词

“整理前检查同音短语”默认启用，只在手动整理时执行，使用已配置的本地Ollama文字模型。云端/自定义接口不会额外自动发送纠词任务。根据上下文提出局部常用词候选，再用等长、原句引用、拼音和保护规则校验；不把模型自评当成准确率。

每批最多8个建议、输入分批、输出有上限，单批45秒；连续失败停止校对并保留原文继续。存在人工修订、明显低质量听写、姓名/数字/否定/条件/语气风险或拼音组件缺失时，只保留候选/提示，不自动采用。通过检查的候选只影响**本次整理输入**；不改原始听写、不重写旧文档，在结果末尾留下修订对照和简要依据。启用会增加生成时间，开关可关闭。

这不是重听原声，不保证同音词都正确；同音不代表同义。严重重复/乱码不能靠“推理”还原为可靠逐字稿。

## 移除无效在线字幕入口

移除“获取整段字幕”“开启CC”等按钮，以及网页字幕自动扫描、自动启动读取和平台字幕请求路径；新录制只走语音。保留手动SRT/VTT文件导入和旧笔记，不删除历史文字。不是隐藏按钮后仍偷偷采集字幕。

## 不应误解为已修复的事项

长文整理的固定100秒请求、非流式与断点续跑仍是独立P0任务；本版服务恢复不等于长文已可靠。未在目标Windows Edge、实际Whisper/Ollama/声学模型和真实视频网站上做完整验收，没有新的准确率或性能保证。实测范围见`qa/V080_TEST_REPORT.md`。
