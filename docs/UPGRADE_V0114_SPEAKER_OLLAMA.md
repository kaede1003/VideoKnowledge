# 说话人自动分组修复 · 服务端 V0.11.4

## 你截图里的根因

原 `SpeakerAnnotator.annotate()` 必须读取 ASR 返回的 `_words`（含词时间戳）；Ollama Qwen3-ASR 只返回整个音频窗口的文字，`_words=[]`，因此无论声音模型是否安装，都走「缺少词级时间戳，未强行归属」分支。不是装好 Ollama 模型就能自动解决的事。

## 本版实际流程

1. 服务通过原有 VKN5 协议从 SQLite 取出已确认、待处理的音频；维持原先的音频所有权窗口、时间戳、重传和原文保留。
2. 可选本地声学模型先识别发言区间和声纹。**声学模型与 Ollama Qwen3-ASR 是两种不同用途的模型**，前者必须单独安装。
3. 一段音频只有一个占主导的声音时，整体转写一次并保守标记 `speakerId=...:spk1` 等；单音声纹覆盖至少90%，且没有超过0.6秒的未归属间隔，否则保留不确定。
4. 存在两人轮流说话时，在声学换人边界拆分音频并分别调用已有 Ollama ASR；重叠音频只转写一次，状态为 `overlap`，不强行归属任何一个人；无可靠声纹则返回 `uncertain`。
5. 切换超过8段或存在过短片段时退回整窗识别，不编造人物身份；若非静音子段识别为空，退回整窗原文而不是悄悄漏字。
6. 分段结果及会话声纹状态仍由原 `StreamStore.commit` 在一个事务中提交。中途失败不会推进已处理音频序号，不会破坏原始记录。

**重要区分：** 声纹编号并非真人身份。自我介绍、字幕人名与演员身份需要额外证据验证，不在本次修复范围。无可靠词级时间戳时按声学分段输出片段级时间区间，不伪造词级定位。

## Windows 升级

在保留原扩展加载目录的前提下，停止当前听写并备份笔记。将升级包合并覆盖工程根目录（例如 `D:\VideoKnowledge_Git_Project`）；勿卸载扩展，勿删除 `.venv`、缓存 SQLite、音频、用户笔记、`ASR_SETTINGS.bat` 或已经安装的 Ollama 模型。

如未安装说话人声学组件，使用已有统一安装器（不是重新安装 Qwen）：

```powershell
cd D:\VideoKnowledge_Git_Project
.\INSTALL_ALL.bat -Profile speaker
```

已有声学模型和组件则跳过上一步。安装完成或覆盖后，重启原服务：

```powershell
.\STOP_LOCAL_ASR.bat
.\START_LOCAL_ASR.bat
```

设置中启用「自动区分发言者」，并**新开一次录音**。健康接口 `http://127.0.0.1:8765/health` 中 `speaker_diarization.available` 应为 `true`，服务版本为 `0.11.4`，ASR后端仍为 `ollama-qwen3-asr`。如果声学模型不齐或自检失败，继续正常听写但标 `unavailable`；不要据此声称自动分组已可用。

## 验收与回退

用包含同一人连续独白、A→B→A轮流讲话、两人抢话的有声样本，检查不同分组的 `speakerId`、音频时间不重叠、原语言正确、内容无丢失、旧声纹在会话内沿用；记录实际 Windows 推理速度和内存。模型无法判断身份时 `uncertain` 或 `overlap` 是符合预期的结果。

回滚只需保留原版 `server/speaker.py` 与 `server/stream_service.py` 以及服务版本配置（推荐用 Git revert），不需要删除数据库、模型或笔记。**旧纯文字稿无法凭空补齐说话人**；需要还保留的原音频才能重新识别。

## 验证范围

新增14个合成/模拟声学分段测试覆盖单声、换声、重叠、未分配、缓存原子提交、重传所有权与故障回退；原有单元回归通过。未调用实际 sherpa-onnx 模型、未联网、未接入目标 Edge 或 Windows。详见 `qa/V0114_SPEAKER_TEST_REPORT.md`。
