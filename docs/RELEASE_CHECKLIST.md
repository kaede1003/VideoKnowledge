# 提交与发布门禁

## 可以提交Git的工程门禁

- [ ] 当前VERSION与源码版本相符；原始基线哈希保留。
- [ ] 全部选定测试真实执行，缺工具/失败不标成功。
- [ ] `check_repo.py --staged`通过，并人工审阅`git diff --cached`。
- [ ] 不提交个人笔记、真实音视频、模型、.venv、数据库、密钥和现场日志。
- [ ] 需求、待修事项、任务状态、验收状态和本次测试报告一致。

## 不能被上述门禁替代的成品发布门禁

- [ ] Windows Edge原生授权、开始暂停停止和长时间采集验收。
- [ ] 真实Whisper/Ollama及人工参考稿评测，记录误差和延迟。
- [ ] 长文超时/持久化/取消修复，通过AC-016/017/018。
- [ ] 旧用户原目录升级、备份、恢复和回滚演练。
- [ ] 依赖和模型来源/版本记录；公开许可和第三方素材权利确认。
- [ ] 已知限制向用户明确；未验收可选功能保留实验标签。

## 源代码归档

工程首次提交并且工作区干净后，可运行`python scripts/package_project.py`生成`dist/`源码ZIP与SHA256。脚本读取Git跟踪文件；不推送、不发布，也不打包`.git`。这只是源代码归档，不是浏览器商店CRX签名或自动更新服务。

本次交接ZIP不带`.git`、远端地址、提交身份和用户历史。将来打tag或发布版本由维护者明确操作。
