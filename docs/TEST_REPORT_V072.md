## 回归重点

1. 不将缺失分数（null）当0分；不将分数当准确率。
2. 重复、纯填充与明确宣传分别记录理由；低质量内容不能因“主题相关”变可信。
3. 简短否定、强调、对比、反例、人物对白不按不相干关键词删除。
4. 只有译文可疑时，原文仍可供带警告的整理。
5. 资料全部被暂缓时不调用生成模型编造正文。
6. 关闭筛选、逐条纳入/排除可逆；所有原始数据仍在笔记/审计导出中。
7. 主题/记录版本改变时不沿用旧分类；无可匹配的原文依据不采用模型的排除建议。
8. 本地分类结果结构错误、超时、云端配置时不排除数据；不自动向远程发送正文。
9. 已有生成任务优先，可选分类延后；取消分类忽略迟到结果。
10. 原有设置、音频采集、说话人、LoRA与多个写作模式没有删去。

## 未完成的验证

**没有在用户Windows Edge、真实Whisper、真实Ollama模型、真实视频网站上完成端到端验收。** 主题分类模型输出全部为模拟值；没有标注测试集上的误筛率/漏筛率、语音错误率或真实性能测量。UI截图也使用模拟内容，不代表原片转写成功。

新筛选不能修复原来已经丢掉的音频、不能保证所有同音词错误被发现。自动判断仅辅助，不承担事实真假核验。分类25秒时限可能不足以供冷模型运行，失败会降级保留而不是悄悄删文。长文生成原有100秒等待/非流式与后台生命周期问题尚未完整修复；这是独立问题。
