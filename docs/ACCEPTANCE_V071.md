# V0.7.1 目标机器验收

先保存数据，扩展/服务都升级到0.7.1；保持原安装目录与扩展ID。不要用“设置连接通过”代替以下验收。

## 原话与译文

取一段有授权、能够人工核对的30—60秒原音，记录时间范围。确定原语种，关闭可选文本纠错/说话人功能。先看识别原文，不先看润色稿。
手工整理四列表：原音原话、模型原文、中文译文、错误类别（漏词/名词/否定/数字/断句/翻译改意/角色）。
用同一片段对比6/12秒窗口，而不是以字幕数量判断准确度。自动字幕只作辅助参照，也可能有错。
对风险告警记录检查原文未消失、译文候选可展开、下游整理仍标疑点；没有报警不表示通过准确性验收。

## 功能

1. 实时记录默认折叠。新增条数增长，但不强行展开；展开/加载更早记录不调用模型。
2. 开始一次即启动；暂停/继续/停止可用。停止后只补旧缓存，不记录后续新时间。
3. 在记录中“核对 / 修订”，保存人工输入；继续收到机器更新时修订仍在。撤销后恢复机器记录，原文不变。
4. 导出核查JSON，确认含来源、时间、原文、译文候选、疑点和人工输入；没有API Key配置；注意文件含私密节目内容。
5. 分别生成知识、剧本、小说、文字稿、自定义。忠实模式不允许提示词擅自转创作，创作润色需显式勾选且标记改写。
6. 新结果不覆盖旧结果。取消/失败不覆盖旧文档；切换、完整阅读、复制和导出不额外调用模型。
7. 对一条人工修订后重新生成，检查新稿采用修订，但旧稿保持历史快照。
8. 文本超过处理上限必须明示，不能悄悄丢最后部分；长文各段串联需人工核验。

## 发布标准

功能测试通过不等于语音/翻译质量达标。用户样本中关键名词、数字、否定和角色归属未核准时，不能将自动文档当作可靠的完整文字稿。应保留失败样例，针对原音再测模型/切分策略。
