## 新增与调整的聚焦回归

1. **合成两小时逐条转写**：每2秒1条，共3600条不同 ID；验证快路追加、旧 ID 修订、末尾记录不丢失。该用例仅验证数据正确性，`node --test tests/long_video_perf_v0121.test.js`，不是目标机器 FPS/耗时证明。
2. **合成两小时深度知识整理**：180段合成台词，各间隔40秒覆盖2小时；将每次模型生成限制为一个模型请求，测试连续中断/检查点复用，证据、章节、最后主题整合完成后 `coverage.covered==180`。模拟模型输出固定文本，**不能证明真实总结没有遗漏重要语义或重复**。
3. **从 r19 单体检查点续跑**：旧 evidence 先写入旧结构，再交由 r20 迁移成按阶段单键保存；验证已完成 evidence 不重复请求，元数据不再随正文无限增长。
4. **主题整合分组收敛**：验证单个回复过长导致无法常规打包时，成对回退分组保留全部 `ids`，而不是无限重试或抛弃来源。
5. **角色模型直接命名**：沿用上下文证据角色测试，允许描述性内容角色名直接展示、新证据足够时自动修订；真实姓名仍须证据，不能因不要审核而编造。
6. **自动审查分级**：`word_timestamps_missing` 和 `correction_suggestion` 信息性标志不增加待审计数；否定/翻译冲突继续提示。真实 Chromium 旧质量用例检查不可信译文不覆盖原文。
7. **浏览器异步存储等待**：字幕 DOM 测试从固定延时改为轮询已落盘记录，匹配新的写入去抖；保留旧源和编辑撤销验证。
