## 新增故障注入与回归重点

- 旧连接仍存活时，新连接获得可重试状态，不把整个录音标成永久失败。
- 过期旧连接的finally和迟到回调不能清掉新连接。
- 缓存拒绝第N包后，不继续读取在途N+1包制造假协议错误；按已持久化序号重发。
- 结果发送任务、数据库查询、单个模型任务异常分别被观测；保留数据和状态。
- 请求关闭/取消时释放连接占用，不把正常取消抛成ASGI错误；新增测试覆盖该收尾边界。
- 应用层心跳、hello应答期限、有上限的退避、断开后健康检查。
- 下载72小时从完成时起算，查看不续期；过期拒绝新播放；只清理有所有权标记的本缓存目录，链接/目录外/未知文件不被递归删除。
- 下载取消/失败/重启中断不能冒充ready；不读取cookie、不下载字幕、不绕过登录与DRM。
- 同音候选仅作用于本次整理输入；保留原句；姓名、数字、否定、条件/语气、非同音候选及证据不足不得静默替换。
- 自动说话人无需用户命名；无角色证据只编号，已有人工名称保留。未安装组件不伪造分组。
- 网页字幕按钮和自动扫描/请求路径已移除；已有笔记和人工文件导入保留。

## 修复过程中出现的失败，不算成功

最后一轮发现连接上下文关闭时偶发CancelledError：原实现可能在清理前再次被取消。现调整为先释放同步所有权，再回收任务，并在ASGI连接边界处理预期取消；补充回归后156项Python测试通过。

运行器使用PIPE时，浏览器子进程保留输出句柄可能使超时收尾受阻。改为写日志文件并只终止当前测试创建的进程树。后续合并运行仍受本轮工具总执行期限影响，因此本报告明确采用分批退出证据，而不虚构单次 `--suite all` 成功。

## 明确未验证、未保证

- 未获得此次用户服务异常退出的完整堆栈/退出码，不能确认现场唯一根因，也不能认定为GPU/内存/驱动问题。
- 未在用户Windows Edge原生tabCapture、实际Whisper/Ollama、真实说话人模型上验收；无字错率、角色错误率、同音纠错准确率或GPU性能结论。
- 没有实际从YouTube/B站下载并播放源视频；下载接口使用替身验证。平台可用性、部分格式所需ffmpeg、JavaScript运行时仍需本机验证。
- 原生模型线程仍在同一服务进程内。库级致命崩溃/系统终止不由Python工作任务监督捕获；故障处理器/退出码改善证据，不等于进程隔离已经完成。
- 服务关闭/关机时不能物理删除72小时缓存，下次启动清理；文件占用可能延迟删除。只清理本插件缓存，不控制用户复制到别处的文件。
- 100秒长文AI请求、非流式与缺乏可靠断点续跑仍独立存在。本次断线修复不能被宣传为已经解决长文生成超时。
- GitHub CI配置未远程执行，没有创建用户仓库或推送。
