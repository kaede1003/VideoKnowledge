## 新增质量与安全断言

1. 本次生产整理方式严格为知识文档、文字稿、自定义；过时 `script`/`novel` 请求回退到知识模式，历史成品依然保留原称呼且可导出。
2. 中文、英文、西班牙语明确自报姓名可提取并绑定当前声纹；不会把“我是一个普通人”“他说：我叫小雨”等泛称和转述当作可靠自报。
3. 第一轮模型缺失姓名候选时，明确的自我介绍仍能走确定性证据路径；不会将名字分配给另一位声纹。
4. 同一发言轮次中的条件短句意外分裂可重新连接；**原文汉字、字母、数值、否定不改变**；不同声音、独立答复仍分开。
5. 断句请求中相邻上下文只读，模型返回内容仍按源文字与ID严格核验。r29 会令旧版本标点检查点失效并重算，不删除源文、既有翻译或旧文稿。
